# かずモン

計算問題に取り組みながら、10種類のモンスターを育てる子ども向け学習Webアプリです。このリポジトリでは、1年生から6年生までを各1単元ずつ試せる無料版を公開しています。

## 特徴

- 小学1年生から6年生まで、各学年1単元を収録
- たまご、ちび、おとなへ成長する10種類のモンスター
- 学習を支える「ねこ先生」
- インストール不要でiPadやPCのブラウザから利用可能

## 利用方法

GitHub Pagesで公開したURLをSafariなどのブラウザで開いてください。学習記録は利用中のブラウザに保存され、外部サーバーには送信されません。

ブラウザや端末を変更した場合、記録は引き継がれません。プライベートブラウズなど保存機能が制限された環境では、記録が残らない場合があります。

## 収録単元

- 1年生：かずを かぞえる
- 2年生：2けたの 数
- 3年生：九九
- 4年生：小数
- 5年生：わりあい
- 6年生：比

学年帯別の有料版では、対象学年の全単元を収録します。
